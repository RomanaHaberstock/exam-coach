# Demo script

For presenting Exam Coach (for example on Day 3). Everything below uses the built-in example, which needs **no AI**: it loads instantly and works even if the AI is slow, out of quota or switched off.

## Before you start

- Open the site in a **fresh browser profile or a private window**, so it starts empty. (Already have data? Use another browser, or Plan → Download backup first.)
- Present **during the day**. Study blocks start at 17:00 by default; in the evening, "Do this now" shows tomorrow's block instead. If you have to present late, set an earlier start time under Plan → Availability before the demo.
- Use a window at least 1000 px wide, zoom 100–125 %.
- If an access code is set, have it ready but you won't need it for the example.

## 2-minute version

| Time | Click | Say |
|---|---|---|
| 0:00 | Start page | "A chatbot can write you a study plan once. It forgets it the moment you close the chat. Exam Coach keeps the plan and changes it when your quiz results say you're behind." |
| 0:15 | **Try it with example exams** | "Two made-up exams with two weeks of made-up studying already in it. The tour starts by itself." |
| 0:25 | Tour step 1: **Week by week** | "The plan is built backwards from the exam: final review on the eve, mock exam a few days before, learning blocks in the order of the material." |
| 0:45 | Next → **Do this now** | "Today starts with a repair review of Probability basics. Nobody planned that by hand." |
| 1:00 | Next → Quiz, Next → **Plan changes** | "Yesterday the student scored 52 % on Random variables, expected was 80 %. The coach saw that this topic builds on Probability basics, which was weak too, so it put the repair time there first. Every change is listed with its reason and the hours moved." |
| 1:30 | Next → **About you** | "Instead of 'visual learner' labels, it measures which study method you still remember 2 days later. Here 'explain it back' works best, so new topics use it." |
| 1:50 | Next → **How it works**, Finish | "That's the loop: plan, study, quiz, compare, change the plan. The AI reads your materials and writes the questions; the coach does everything around it." |

## 5-minute version

Do the 2-minute version, then add:

1. **Take a quiz live (1 min).** Today → **Quiz** on the repair review (or Quiz tab → Statistics → Probability basics) → **Use the example questions (no AI needed)**. Answer two or three wrong on purpose → **Submit answers**. Point at "What the coach changed": extra hours for Probability basics, taken from later blocks. Then **See updated plan**.
   Say: "This is the feedback loop: a score below where you should be changes the plan immediately."
2. **Block content (30 s).** Plan → Day by day: each block says which pages, what to do and what you should have at the end.
3. **Your own material (1 min, needs the AI).** Exams & materials → Add exam → upload a short PDF (a few pages) → **Analyze materials**. The AI finds topics, subtopics with pages and key terms, and the plan appears. Skip this if the AI is slow (see below).
4. **Privacy (15 s).** "No accounts. Everything is saved in this browser; only the text needed for an AI request is sent."
5. **Close on How it works** and the table "What a chatbot can't do here".

## Questions you may get

- **"Couldn't I just ask a chatbot?"** For explaining a topic, yes, and Exam Coach uses an AI for that. A chatbot doesn't remember your results, doesn't notice you're behind, doesn't schedule spaced reviews and can't measure which method works for you. Show Plan changes.
- **"Is the example real data?"** No, it's made up and marked as example data, but it ran through the real planner and feedback loop, so every message is what the app writes for a real student.
- **"What if the AI makes mistakes?"** Topics, weights and hours can be edited; multiple-choice is graded on the page; written answers that try to talk the grader into points get 0.

## If the AI is slow or fails

- Stay in the example: nothing in it calls the AI (tour, plan, quiz with example questions, plan changes, learning profile).
- If a live analysis hangs: press **Stop**, say "the free AI tier is busy right now, that's why the example doesn't depend on it", and continue with the example quiz.
- If something looks wrong: Today → **Remove example data** (click twice) → **Try it with example exams** gives a fresh example in a second.
